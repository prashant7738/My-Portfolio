 ## I build AI systems that ship
 
 I am a Computer Engineering student and AI Engineer focused on turning LLM capabilities into reliable products. I build **retrieval-augmented generation (RAG) systems**, **multi-agent workflows**, and **LLM-powered backends** with the engineering required to make them useful in production: grounded outputs, validation gates, fallbacks, isolated execution, authentication, and clear user experiences.
 
 My full-stack background helps me take AI features beyond notebooks. I can design the retrieval layer, build the API, connect the database, ship the frontend, and make the complete workflow usable by real people.

 ## Featured work
 
 ### [Contextra AI](https://contextra-ai.vercel.app/) · [Source](https://github.com/prashant7738/Contextra-AI)
 
 Production-minded document intelligence platform for grounded PDF question answering. It combines a hybrid OCR pipeline, BGE-small embeddings, PostgreSQL/pgvector retrieval, citation-backed responses, Pareto 80/20 summaries, and smart flashcard generation. Built with FastAPI, SQLAlchemy, Alembic, Astro, and React.
 
 ### [AnalyzeAI](https://multiagent-analyst.vercel.app/) · [Source](https://github.com/prashant7738/multiagent-analyst)
 
 An explainable multi-agent data analyst for CSV, Excel, JSON, JSONL, and Parquet files. A six-stage LangGraph workflow combines deterministic Pandas/SciPy analysis with bounded LLM assistance to produce quality scores, findings, signal-driven charts, recommendations, dataset chat, and HTML/PDF reports. The backend includes SSE progress, fallbacks, validation gates, cancellation, isolated run artifacts, and a focused 205-test regression suite.
 
 ### The Automaton Boardroom
 
 An autonomous software micro-agency that turns an app idea into technical specifications, generated code, an isolated E2B sandbox, and verification tests before human review. Built with LangGraph, LangSmith, Streamlit, Groq, and Gemini, with prompt-safety guardrails and model fallbacks for resilient, cost-aware execution.
 
 ### [Live Bidding NP](https://project-bidding-dbms.vercel.app) · [Source](https://github.com/prashant7738/ProjectBiddingDBMS)
 
 Real-time auction platform built with React, Django Channels, Redis, PostgreSQL, and SQLAlchemy Core. It handles concurrent WebSocket bidding and uses JWT authentication in HttpOnly cookies.
